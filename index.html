Cara menjaga data tabungan

Buat album, lalu catat setoran atau penarikan. Saldo dihitung dari catatan. Di Riwayat, tombol unduh membuat CSV sesuai filter. Gunakan Unduh cadangan untuk menyimpan seluruh data beserta foto, lalu Pulihkan cadangan jika ingin memindahkannya ke browser lain.

Di mana data saya disimpan?

Pada mode perangkat, data tabungan disimpan di browser ini. Browser atau perangkat lain memiliki penyimpanan terpisah. Menghapus data situs atau memakai sesi privat dapat menghilangkan data lokal. Pada mode server pribadi, data berada di database pemilik server dan pengingat dapat diproses oleh server. Jaga akses ke berkas cadangan yang memuat informasi tabungan.

Cadangan dan pemulihan

Di perangkat ini

Cadangan berisi album, catatan, rencana, dan foto. Simpan berkas secara pribadi. Pemulihan mengganti data perangkat setelah pratinjau dan konfirmasi. Maksimal 32 MB.

Penyimpanan perangkat dan server pribadi terpisah. Mengganti sumber data tidak memindahkan isi tabungan.
